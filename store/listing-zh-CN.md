# RepoLingo 商店文案（简体中文）

## 简短说明

本地优先的 GitHub 中文阅读层：无需 API Key，原文与译文一键切换。

## 详细说明

RepoLingo 为 GitHub 的 README、Issue、Pull Request、Discussion 和 Release 提供中文优化翻译。默认调用浏览器内置 Translator API，不要求账号或 API Key；语言包准备完成后可离线使用。

代码、命令、URL、路径、版本号、Commit SHA、参数和变量名会被保护。译文校验失败时保留原文。用户可以在原文、译文和双语模式之间无刷新切换。

OpenAI、Gemini 和 DeepSeek 增强翻译为完全可选能力，默认关闭，仅在用户主动配置并授权后发送经过保护的自然语言段落。

RepoLingo 不采集遥测，不展示广告，不保存长期翻译历史，不包含云端账号系统。

## 单一用途说明

帮助简体中文用户阅读 GitHub 上的英文自然语言内容，同时保护开发者原始技术结构并提供即时原文核验。

## 权限说明

- 存储：保存显示偏好和用户主动配置的增强服务设置。
- github.com：识别并呈现可翻译的 GitHub 自然语言区域。
- 可选服务域名：仅在用户主动启用对应增强服务时申请。
