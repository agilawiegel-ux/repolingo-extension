THREE PROMISES

翻译是辅助层，
原文始终都在。

01

默认留在本地

浏览器内置语言包负责翻译。RepoLingo 不打包模型，不设云端账号，也不要求用户先配置服务。

02

技术实体不碰

代码、命令、URL、路径、版本、SHA 和标识符经过占位符保护；校验失败就显示原文。

03

疑问一键核验

原文、译文和双语模式即时切换，不刷新页面，不打断滚动、链接、锚点或折叠状态。

会翻译

自然语言内容

  • README 与仓库简介
  • Issue 与 Pull Request
  • Discussion 与回复
  • Release 说明
R

不会翻译

开发者原始结构

  • 代码、命令与 Diff
  • 文件树、日志与输入框
  • 链接、标题锚点与按钮
  • GitHub 操作控件

OPTIONAL · 完全可选

本地已经够用，
增强只是选择。

OpenAI、Gemini 和 DeepSeek 接口已经预留，但默认全部关闭。只有你主动选择服务商、填写自己的 API Key 并授权对应域名后，经过保护的自然语言段落才会发送出去。

不付费也能完整使用。 RepoLingo 不会自动切换到付费 API，也不会采集遥测。

INSTALL

四步开始阅读。

  1. 01
    下载

    从 GitHub Release 下载最新 ZIP 并解压。

  2. 02
    打开扩展页

    进入 chrome://extensions 或 edge://extensions。

  3. 03
    加载

    开启开发者模式，选择“加载已解压的扩展程序”。

  4. 04
    点击中文

    访问 GitHub，点右上角的瓷青双语滑片。
